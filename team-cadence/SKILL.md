# Team Cadence — ritme dan pengejaran tim internal

## 1. Aturan main tim (sumber: diumumkan Khusnul)
Task ≥ 2 jam ada di lab0 · update sebelum 16:00 WIB dengan bukti · Blocked hari itu juga ·
tenggat baru diajukan SEBELUM lewat · komitmen disepakati Senin · reminder dibalas update, bukan "siap".

## 2. Komitmen mingguan (Senin 08:30)
1. Per orang: task jatuh tempo minggu ini (baseline) + sisa minggu lalu.
2. Kurangi kapasitas: cuti, libur, onsite, alokasi proyek lain (skill resource-capacity).
3. Total > 100% kapasitas → tandai dan usulkan yang digeser.
4. Issue approval ke lead tim, tenggat 10:00. Setelah disetujui → tag *Target Minggu Ini* di lab0.

## 3. Cek tengah minggu (Rabu 14:00)
Komitmen dengan realisasi < 40% → pesan ke [INT] tim (tanpa menyalahkan) + daftar ke lead.

## 4. Scorecard (Jumat 15:00)
- Tim (ke grup [INT] tim): komitmen tercapai %, kepatuhan update %, task telat, apresiasi (I4).
- Per orang (issue privat ke lead): tercapai / geser (alasan) / gagal; hari update x/5.
- Target: komitmen ≥ 85%, update ≥ 95%, telat ≤ 5%, Blocked > 2 hari = 0.
- Dua minggu pertama proyek/tim baru: mode ukur, tanpa warna merah.

## 5. Tangga pengejaran internal (hari kerja setelah tenggat)
H-1 brief pagi · H+1 daftar "lewat tenggat" di brief · H+2 japri PIC (draft I2, dikirim Rizky) ·
H+3 japri lead (I3) + Issue · H+5 [INT] PMO untuk Aga + scorecard ·
Pola 3 minggu atau H+7 → coaching oleh lead, lalu management review.
Lead = PIC → langkah H+3 langsung ke Aga.

## 6. Batasan
Agent menyajikan fakta (status, tanggal, dampak). Teguran dan penilaian oleh lead/Aga.
Rizky bertanya fakta atas dasar aturan main, bukan menilai orang.
Apresiasi di grup, koreksi lewat japri.
